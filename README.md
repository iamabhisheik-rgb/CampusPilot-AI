# CampusPilot-AI
CampusPilot AI - A Multi-Agent AI Copilot that automates academic and administrative workflows for colleges using Gemini AI, RAG, FastAPI, React, and Supabase.
# CampusPilot AI

## Problem Statement
Students spend a lot of time reading PDFs and making notes manually.

## Solution
CampusPilot AI lets students upload PDFs, chat with AI, generate notes, quizzes, and study plans.

## Features
- PDF Upload
- AI Chat
- Notes Generator
- Quiz Generator
- Study Plan Generator
- Dashboard

## Tech Stack
- React
- FastAPI
- SQLite
- Gemini AI

## Installation

### Backend
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload

### Frontend
cd frontend
npm install
npm run dev
